# Hi, I'm Brian 👋

I'm building a CRPG, starting with the engine. Day to day I work in Elixir, Phoenix, and LiveView.

## What I'm building

**[Corundum Engine](https://github.com/corundumengine/corundum)** is a 2D isometric CRPG engine in C++23. Open source (Apache 2.0), with cross-platform rendering
(Metal/D3D11/GLCore on GLFW + Sokol) and an ImGui editor toolset: tilesmith, spritesmith, loom.

**Project Keystone** is the game I'm building on it. The codename fits: the game is what brings the engine together.
